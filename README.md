# dotfiles

Starship prompt + Neovim config + Foot terminal.

## Setup

### Linux
```bash
git clone git@github.com:NamesAreOverrated/dotfiles.git ~/.dotfiles
~/.dotfiles/bootstrap.sh
```

### Windows
```powershell
git clone git@github.com:NamesAreOverrated/dotfiles.git $HOME\.dotfiles
.\bootstrap.ps1
```

### Syncing
Edit files in the repo directory (`~/.dotfiles`), then `git add`, `git commit`, `git push`.
On your other machine: `git pull`.
